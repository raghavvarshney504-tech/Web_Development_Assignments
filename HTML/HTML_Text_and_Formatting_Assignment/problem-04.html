(Algebra):
Algebraic formulas are mathematical identities used to simplify expressions and solve problems quickly. They show relationships between variables and help reduce lengthy calculations.

(i) (a+b)2 = a2 + b2 + 2.a.b


(ii) (a-b)2 = a2 + b2 - 2.a.b


(iii) (a+b)3 = a3 + b3 + 3a2.b + 3b2a


(iv) (a-b)3 = a3 + b3 - 3a2.b + 3b2a


(v) (a+b)*(a-b) = a2 - b2

Learning these formulas helps students solve mathematical problems quickly and accurately.
