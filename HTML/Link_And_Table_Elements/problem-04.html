SSD (Solid State Drive)
An SSD is a storage device used to store the operating system, applications, documents, and other files. It provides faster boot times and quicker file access than a traditional HDD.
```
RAM (Random Access Memory)
RAM is temporary memory used by the computer to store data for currently running programs. Higher RAM helps the laptop handle multiple applications smoothly.
CPU (Central Processing Unit)
The CPU is the main processor of a laptop. It performs calculations, executes instructions, and controls many of the computer's operations.
GPU (Graphics Processing Unit)
A GPU processes graphics and images. It is useful for gaming, video editing, 3D applications, and AI or machine-learning tasks.
Refresh Rate
Refresh rate is the number of times the display updates its image every second, measured in Hertz (Hz). A higher refresh rate can make scrolling, animations, and motion appear smoother.
Battery Capacity
Battery capacity indicates how much energy a laptop battery can store and is commonly measured in watt-hours (Wh). A higher capacity can contribute to longer battery life, although actual battery life also depends on the laptop's hardware and usage.
```
